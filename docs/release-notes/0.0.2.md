## Highlights

KM Companion 0.0.2 adds a Dex for Pokémon Royal Sword, refreshes the Calculator and run references for the expanded roster, and adds optional offline Pokémon artwork. The Royal Sword profile covers 841 species present in the game and includes 90 Mega forms.

## Dex And Artwork

* Browse all 1,025 National Dex entries. Search by name, form, or number and open Mega forms from their base species. Each available entry shows the profile's stats, abilities, evolutions, type defenses, learnsets, and recorded encounter locations.
* Browse Level up, TM, TR, Tutor, and Egg moves separately. Each list has its own search and move details.
* Find static sprites and animations for all 90 Royal Sword Mega forms and the 129 species added to the profile. Choose Download artwork at startup or use **Settings → Artwork** later. An update reuses matching files and downloads missing or changed pictures when you choose Download artwork.

## Pokémon Royal Sword

* The Calculator and Dex share the updated Pokémon, form, Mega Stone, ability, and move data. The Calculator supports rules for Dragonize, Piercing Drill, Aura Guard, Eelevate's Ground immunity, and Mega Sol's effects on supported moves.
* Sword and Shield saves and `.pk8` files use Royal Sword species, form, ability, and item IDs. Imported Pokémon keep their held Mega Stones, and supported bag entries use the profile's item names.
* Trainer teams, trades, encounter tables, and matched Route Items pickups reflect the refreshed profile. Encounter odds use each slot's share of its full table, and weather cards show the slots that differ from normal weather. Existing catches and pickup progress carry forward.

## Workspace And Mod Submissions

* Storage cards adapt to the available space while Team keeps all six Pokémon in one row. Pokémon selectors keep names readable when pictures are unavailable, and automatic Pokémon color coding works again.
* The [mod submission guide](https://github.com/KotMatrosk1n/KM-Companion/blob/v0.0.2/docs/mod-submissions.md) includes templates, examples, and a checker for proposed game data. The existing trainer team import remains available.

## Installation And Maintenance

* Update from 0.0.1 through **Settings → Updates**, or download the Windows x64 setup from the release assets below. Windows releases remain unsigned.
* Updates and repairs keep downloaded artwork. A successful uninstall removes the current Windows account's downloaded Pokémon artwork while preserving saved runs and settings.
* The desktop app uses Electron 45.3.1 with updated minimatch dependencies. Source builds use Node.js 26, and the Windows installer uses .NET 11. See [Development](https://github.com/KotMatrosk1n/KM-Companion/blob/v0.0.2/docs/development.md) for build instructions and [Licensing](https://github.com/KotMatrosk1n/KM-Companion/blob/v0.0.2/LICENSING.md) for matching sources and retained notices.
