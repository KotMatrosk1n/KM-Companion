## Highlights

KM Companion 0.0.1 brings battle planning, team storage, encounter tracking, trainer references, item progress, and run backups together in its first public release. Pokémon Royal Sword is the first bundled profile, with support for additional ROM hacks through separate profiles and trainer packs.

## Battles And Teams

* Compare damage rolls and survival chances in Singles and Doubles, with Pokémon details and battlefield controls beside the calculation. The engine supports Generations 1 through 9, and each profile applies its own game data and rules.
* Import compatible save files and Pokémon files into the active profile. Keep teams, boxes, and imported inventory with the run while preserving separate data for other profiles.
* Team keeps larger animated sprites and visible names. Box, Box 2, Compost, and Trash use compact static sprites with color coding and names available on hover.
* Royal Sword storage pages hold 30 Pokémon in six columns and five rows. Storage cards adjust to the available space without changing page capacity when the window is resized or drawer tools are opened.

## Royal Sword

* Browse encounters by location, method, and weather. Normal, Royalocke, and Nuzlocke keep separate progress, with the active rules available beside the tracking controls.
* Inspect trainer teams, moves, abilities, items, and stats. Mark defeated trainers and keep notes for individual battles.
* Track Route Items pickups and completed locations, with Post Game rewards grouped at the end. This reference uses the Sword/Shield 1.3.2 base game guide and retains its source links and known limitations; it is not a verified Royal Sword placement list.
* Use the Royal Sword calculation profile and Sword/Shield battle simulator. Royal Sword keeps its own data and disabled EV input separate from other profiles.

## Runs And Settings

* Back Up Run and Restore Run cover the selected profile's teams, boxes, notes, imported inventory, and recorded progress. Undo Last Restore recovers the run replaced by the most recent restore.
* Reset Run clears encounter, trainer, and item progress after confirmation while retaining teams, boxes, inventory, notes, settings, and other profiles.
* Choose Classic, Renegade, Royal, or Sovereign. The update notification stays yellow with dark text in every theme.
* Check for updates automatically after launch or manually in Settings. Review release notes and confirm Install Update before downloading and installing a newer version.

## Installation And Maintenance

* Install the Windows x64 setup from the release assets. KM Companion uses its field guide icon across the app and setup, and retains compatible saved data from KM Calculator.
* Windows releases are unsigned. Update downloads use HTTPS and the digest in the release metadata, without Authenticode publisher verification.
* Version 0.0.1 starts the public version sequence. Earlier 0.4.x development builds do not offer it as an automatic update. Back up the run and follow the [development build transition](https://github.com/KotMatrosk1n/KM-Companion/blob/v0.0.1/installer/windows/README.md#upgrade-and-uninstall-behavior) before installing.
* Update Electron to block compromised eMudhra intermediate certificates in Chromium and Node networking. Update the build tooling's URI parser for its scheme, host, and path handling fixes.
